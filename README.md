## About

Backend & distributed-systems engineer at Flipkart. I build high-throughput services and care most
about the parts people only notice when they break — memory behaviour, failover, and capacity.
On the side I build small systems from scratch (an LSM-tree storage engine, a JVM memory-leak agent)
to actually understand the tools I depend on.

**Into:** system design · JVM internals · database internals &nbsp;•&nbsp; **Also:** Codeforces Specialist, 1000+ DSA problems solved.
