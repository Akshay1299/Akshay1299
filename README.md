### 🧠 About

I like the unglamorous problems — the ones with **scale**, **failure modes**, and **3 a.m. pages** hiding in them.
At Flipkart I work on high-throughput backend platforms; on the side I build low-level systems to understand
how the tools I use actually work. I don't just ship features — I engineer them to be resilient, efficient, and
*boringly reliable*.

- 🔭 **Currently:** backend platforms @ Flipkart (Java 21 · Spring Boot · gRPC · HBase)
- 🌱 **Geeking out on:** System Design · JVM Internals · Database Internals
- 💬 **Ask me about:** LSM-trees, memory leaks, multi-DC failover, or why your pod got OOMKilled
- ⚡ **Fun fact:** Codeforces Specialist · 1000+ DSA problems solved
